## 4. Architectural Taxonomy & Design Tenets

### The 4-Layer Taxonomy
* **Layer 1 (Deterministic Actuators - `llm-functions`):** 31 atomic Bash scripts with `argc` schemas running in ~0.05s.
* **Layer 2 (Autonomous Execution Engine - `aichat`):** Multi-turn LLM reasoning loop, process-isolated sub-agent trees (`aichat --agent`), native in-process Rust MCP, stream routing (auto-capping >16KB, pipe chains, file receipts), and out-of-band `/dev/tty` telemetry.
* **Layer 3 (Workspace Supervisors - `dot-agent-deck`, `bohay`, Tmux):** Human-in-the-loop (HITL) approval cards, multi-pane terminal multiplexing, and long-lived Git worktree management.
* **Layer 4 (Enterprise Control Planes - `TrueForge`, Portkey):** Multi-tenant RBAC, enterprise audit logging, and cloud fleet coordination.

### The 5 System-Level Design Tenets
1. **System-Level Execution Scope:** Not artificially constrained to a Git repository/worktree; operates across the entire OS, host filesystems, network tools, daemons, Kubernetes, and cloud APIs.
2. **Process-Isolated Delegation (Zero Cascade Risk):** Every sub-agent runs as an independent OS process with a dedicated PID, turn budget, and cost ceiling.
3. **Declarative Stream Protection & Context Hygiene:** Auto-capping and tool piping prevent massive log/metric dumps from polluting LLM context.
4. **"Triage in Parallel, Actuate in Sequence":** Read-only diagnostic swarms run concurrently with zero collision; state-mutating actions are staged and executed in sequence.
5. **Universal Portability & Zero-Dependency Baseline:** Single static `musl` binary (~14 MB) + pure Bash/`argc` tooling for minimal 64 MB RAM bastions, air-gapped jump-boxes, and legacy servers.
